# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by emailing security@example.com. Please do not disclose the vulnerability publicly until we have had a chance to address it.

## Supported Versions

We release security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |
